# 自包含 ImGui UI 层，领域通过接缝注入

从 auto-cookie 迁移 UI 到 cr-auto 时，我们把 ImGui 控制面板与悬浮胶囊放入自包含的 `internal/ui` 包：它不 import 任何领域包，面板草稿使用本地精简结构（仅含渲染与编辑所需字段），宿主通过 `Publish*` 状态发布与 `Command` 命令两个接缝注入数据并消费用户动作。

考虑过的替代方案：照搬 `settings`/`capabilities`/`engine` 类型（会让全新项目背上前项目的领域模型），以及为每个依赖定义接口（在尚无领域时为未来抽象，属于过度设计）。两者均被否决；等引擎与任务域迁移进来时，它们只通过既有接缝接入，不需要改动 UI 层。
