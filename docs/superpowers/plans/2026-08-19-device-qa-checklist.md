# 控制面板真机验收清单

在 AutoGo 插件下用 F7 跑到 Android 设备/模拟器上，逐项勾选。桌面 `go test` 不能替代本清单。

可选编译检查（本机无 NDK/`libimgui.so` 时会 skip，不算失败）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-android-ui.ps1
```

桌面回归：

```
go test ./internal/ui . -count=1
```

## 清单

- [ ] 1600×900：启动成功后才出现悬浮胶囊；启动失败（存盘错误）控制面板仍在。
- [ ] 非 1600×900 或旋转成 900×1600：启动禁用，原因含分辨率。
- [ ] 截图隐身：识别诊断「立即识别」与引擎一轮，截图不含控制面板/悬浮胶囊像素（目视）。
- [ ] 连续点「立即识别」10 次：无纹理泄漏、无崩溃。
- [ ] 关闭脚本：无残留 ImGui 窗口。
- [ ] OCR 注入成功后任务可启用；ppocr.New 失败时任务全部「等待设备 OCR 验收」。
- [ ] 安全特征采集后：进商店购买框停机且未点确认。
- [ ] 停止任务 ≠ 退出脚本；退出需二次确认。
- [ ] 计划等待：悬浮胶囊显示等待，暂停无效。
- [ ] 手指点悬浮胶囊按钮可稳定命中（≥48px）。
